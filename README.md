## Proprietary payload

This repository is intentionally **configuration-only**.

`proprietary/` is gitignored and is not part of any commit. The generated
`Android.bp` and vendor makefiles refer to files under `proprietary/`, so a
build requires a local extraction from the owner's stock dump first:

```bash
cd device/ulefone/gq5012bf1
./extract-files.py <path to the extracted stock partitions>
```

or, without re-extracting, regenerate only the makefiles:

```bash
./setup-makefiles.py
```

Proprietary binaries, firmware, calibration data and keys are not committed to
this repository.

## Status

The configuration is generated from the real GQ5012BF1 `proprietary-files.txt`
and was included in a successful LineageOS 24.0 / Android 17 Kati product
evaluation (`PRODUCT_EVALUATED`). It has not been built with the proprietary
payload present in this checkout. The full-ROM vendor image is not
runtime-validated; see the device tree README and the C52 research report for
the stock SELinux policy blocker.
